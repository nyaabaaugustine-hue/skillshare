# SkillBridge NGO Website

A responsive Next.js homepage starter for SkillBridge, a Ghana-focused technology education initiative for children aged 7–16.

## Requirements
- Node.js 18.18+ (Node.js 20 LTS recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Before publishing
1. Replace the sample email address and any placeholder contact details.
2. Replace the remote demo photography with approved SkillBridge photographs.
3. Connect Register and Login to your real authentication/LMS routes.
4. Add verified impact statistics, safeguarding policy, privacy policy and organisational details.
5. Connect donation, volunteer and contact forms to a secure backend.

## Notes
- This is the public-facing homepage starter. It does not include a working database, authentication, payment processing or admin dashboard yet.
- All main navigation links currently jump to sections on the homepage or use clearly marked starter destinations.
- UI buttons use a 6px border radius.
